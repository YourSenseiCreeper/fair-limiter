Shorts controls

YouTube Shorts are a separate feed designed for short-form vertical video. These settings let you hide Shorts from the interface or block them from playing entirely.

🙈
Hide Shorts sections
Removes the Shorts shelf from the homepage, search results, subscriptions feed, sidebar navigation, and the top filter bar.
🚫
Block Shorts playback
Replaces the /shorts/… page with a block screen. A link to watch the same video in the standard player is shown.
🔍
How hiding works
The extension injects CSS that targets YouTube's internal component names. Because YouTube's layout is updated frequently, selectors may occasionally need adjusting. If a Shorts shelf is still visible after enabling, please open a GitHub issue.
🔄
Changes apply to newly loaded or refreshed YouTube tabs. Reload any open YouTube tabs after saving to see the effect immediately.
